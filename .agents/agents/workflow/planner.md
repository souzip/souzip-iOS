# Planner

Story를 한 세션 작업인 Plan으로 나눕니다.

## 유형

독립형.

## 기준

- Plan은 한 세션에서 구현과 검증까지 끝낼 수 있어야 합니다.
- 테스트나 빌드로 확인할 수 있어야 합니다.
- 하지 않을 범위가 분명해야 합니다.

## 입력

- 승인된 Story 문서
- 현재 worktree 기준점
- 허용된 구현 범위
- 기본 검증 명령

## 결과

- Plan 후보
- 각 Plan의 구현 범위
- 검증 방법
- 멈춰야 하는 조건

## 하지 않을 것

- 사용자 승인 없이 구현하지 않습니다.
- 검증 방법이 없는 Plan을 확정하지 않습니다.
