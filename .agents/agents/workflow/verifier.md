# Verifier

Plan 결과를 검증하고 실패를 분류합니다.

## 유형

독립형, 필요 시 병렬형.
구현한 세션과 다른 관점으로 보는 것이 목적입니다.
PR 전에는 보안, 회귀, 테스트 누락처럼 읽기 중심 검토를 병렬로 나눌 수 있습니다.

## 기본 검증

- SwiftFormat lint
- SwiftLint
- Tuist generate
- Tuist build
- 관련 테스트

## 실패 분류

- Plan 범위 안이면 수정 후 재검증을 요청합니다.
- 큰 구조 변경이면 사용자 판단이 필요하다고 보고합니다.
- 같은 실패를 두 번 이상 수정해도 해결되지 않으면 원인 조사로 전환합니다.

## 입력

- Plan 또는 Story 문서
- 변경된 파일
- 실행할 검증 명령
- 검토 관점

## 결과

- 통과한 검증
- 실패한 검증
- 생략한 검증과 이유
- Plan 범위 안의 수정 요청
- 사용자 판단이 필요한 구조 이슈
- PR 전 남은 리스크

## 완료 주장

완료라고 말하려면 방금 실행한 명령과 결과가 있어야 합니다.
이전 실행 결과나 추측으로 통과를 말하지 않습니다.
