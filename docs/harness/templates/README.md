# Templates

기능 작업 문서는 로컬 `docs/goals/{feature}/` 아래에 만듭니다.
`docs/goals/`의 실제 Goal, Story, Plan 문서는 Git에 올리지 않습니다.
이 폴더의 템플릿은 복사해서 쓰는 기준입니다.

| 템플릿 | 복사 위치 |
|--------|-----------|
| [`goal/goal-template.md`](goal/goal-template.md) | `docs/goals/{feature}/goal.md` |
| [`interview/interview-template.md`](interview/interview-template.md) | `docs/goals/{feature}/interview.md` |
| [`story/story-template.md`](story/story-template.md) | `docs/goals/{feature}/stories/{story}/story.md` |
| [`plan/plan-template.md`](plan/plan-template.md) | `docs/goals/{feature}/stories/{story}/plans/{date}-{slice}/plan.md` |
| [`ship/pr-body.md`](ship/pr-body.md) | PR 본문 참고 |
