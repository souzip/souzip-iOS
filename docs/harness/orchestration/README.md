# Orchestration

이 폴더는 하네스를 개선하기 위한 설계 노트를 둡니다.
지금은 Codex 기준으로 다시 구체화하는 출발점입니다.

## 남기는 의도

- AI가 먼저 인터뷰로 요구사항과 이해관계를 명확히 합니다.
- 목표 문서를 기준으로 Story를 나눕니다.
- Story 하나는 PR 하나입니다.
- Story 안에는 여러 Plan이 있을 수 있습니다.
- 구현보다 검증까지 포함한 작업 흐름을 만듭니다.

## 다음 단계

1. 첫 실제 Goal 인터뷰로 하네스를 시험합니다.
2. Story 후보를 만들고 active Story 1~2개를 고릅니다.
3. worktree, Plan, 검증 흐름에서 부족한 문서를 보정합니다.
