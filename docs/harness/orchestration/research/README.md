# Research

하네스를 다시 구체화하기 위한 조사 공간입니다.
범위가 크기 때문에 한 문서에 모두 넣지 않고, 주제별로 나눠서 관리합니다.

## 조사 트랙

공통 레퍼런스 후보는 [`reference-candidates.md`](reference-candidates.md)에 둡니다.
각 트랙은 이 후보 중 필요한 것만 깊게 봅니다.

1. 완료: [`01-workflow-structure.md`](01-workflow-structure.md)
   Goal → Story → Plan 흐름과 PR 단위 작업 구조

2. 완료: [`02-subagents.md`](02-subagents.md)
   서브에이전트 역할 분리, 독립 세션, 병렬 가능성

3. 완료: [`03-interview-goal-doc.md`](03-interview-goal-doc.md)
   인터뷰 방식과 목표 문서 템플릿

4. 완료: [`04-verification.md`](04-verification.md)
   Plan 종료 검증, 실패 처리, 큰 변경 중단 기준

## 진행 방식

각 트랙은 같은 형식으로 정리합니다.

- 우리가 답해야 할 질문
- 참고할 레퍼런스 후보
- 조사하면서 얻은 패턴
- Souzip 하네스에 반영할 결정
- 아직 남은 질문

한 번에 모든 결론을 내리지 않습니다.
트랙 하나씩 조사하고, 필요한 부분만 `workflow`, `agents`, `templates`, `verification` 문서에 반영합니다.
